# Gacha Hub Info

Данные для панели лаунчера Gacha Hub: промокоды, баннеры персонажей и видео
Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Wuthering Waves и
Arknights: Endfield.

Файл собирается автоматически раз в час:
https://ertezy.github.io/Gacha-hub-info/hub.json

Не связано с разработчиками игр. Материалы принадлежат правообладателям.

Список новостей Wuthering Waves на официальном сайте Kuro Games тоже
запрашивается — раз в 6 часов, — но только как сигнал «не вышел ли баннер,
которого фандом ещё не знает». В файл данных из него ничего не копируется:
если сигнал сработал, сборщик лишь открывает задачу в репозитории со ссылкой
на новость и её датой.

У каждого кода есть ссылка на страницу-источник (`source`), у каждого баннера —
ссылка на страницу вики (`url`). Картинки не хранятся: в файле только ссылки.

Файл данных распространяется по лицензии CC BY-SA 4.0.

Коды Arknights: Endfield автоматически не собираются: открытого источника со
сроками нет. Их можно вписать в файл правок.

## Файл правок

`overrides.json` — чтобы добавить код или баннер, которого источники ещё не
знают, или скрыть ошибочную запись. Правится прямо на сайте GitHub: открыть
файл, нажать карандаш, сохранить. Через пару минут правка попадёт в данные.

```json
{
  "codes": [
    { "game": "endfield", "code": "ENDFIELDGIFT", "rewards": "150 Oroberyl", "expires": "2026-10-01 23:59 UTC+8" }
  ],
  "banners": [
    { "game": "wuthering", "title": "Thousand Futures Mirrored in Snow", "featured": ["Hiyuki"],
      "starts": "2026-09-10 10:00 UTC+1", "ends": "2026-09-29 11:59 UTC+1" }
  ],
  "hide": [
    { "game": "genshin", "code": "WRONGCODE" },
    { "game": "wuthering", "banner": "Название баннера" }
  ]
}
```

- `game`: `genshin`, `hsr`, `zzz`, `wuthering`, `endfield`.
- Время — строкой с поясом: `2026-10-01 23:59 UTC+8`. Срок кода можно не писать.
- Сроки баннеров показываются по европейскому серверу (UTC+1).
- Сгоревшее выпадает само, чистить файл не нужно.
- Ошибку в файле покажет красный крестик у коммита; сбор при этом не ломается.

Проверить сборщик локально, не публикуя результат: `npm run collect -- --dry-run`
(флаг обязательно после `--`, иначе npm его проглотит и запуск станет боевым).

## Задачи с меткой «сборщик»

Сборщик сам открывает задачи и сам их закрывает:

- **Не работает: …** — источник не отвечает или поменял разметку. Пока он
  сломан, в файле остаются прошлые данные.
- **Новый баннер Wuthering Waves: фандом его ещё не знает** — вышел официальный
  анонс, а страницы на вики пока нет. Впишите баннер в `overrides.json`.
- **Файл правок не читается** / **Файл данных не прошёл проверку**.
- **Сделай любой коммит: расписание скоро выключится** — GitHub выключает
  расписание после 60 дней без активности в репозитории.
